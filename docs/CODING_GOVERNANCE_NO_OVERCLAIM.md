# Coding governance no-overclaim rule

The following implications are forbidden:

- source exists ⇒ tests passed,
- plan valid ⇒ command executed,
- command deterministic ⇒ result correct,
- no review findings ⇒ no defects,
- mergeable PR ⇒ certified capability,
- zero-job CI startup failure ⇒ code failure,
- zero-job CI startup failure ⇒ code pass,
- provisional denominator event ⇒ certified release.

Evidence must remain classified at the level actually demonstrated.
