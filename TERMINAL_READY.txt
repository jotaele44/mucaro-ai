ARTIFACT PATH / SHA-256 CHECKS
Use the exact artifact path printed by the build or handoff command.
macOS/Linux: shasum -a 256 <artifact-path>
Windows PowerShell: certutil -hashfile <artifact-path> SHA256
Compare the observed digest with the exact manifest/receipt digest. A mismatch is FAIL, not a warning.

FAILURE HANDLING
Missing dependency or unavailable required runtime = BLOCKED until independently resolved.
Test or validation failure = FAIL for that gate; preserve the output.
Checksum mismatch = FAIL; do not relabel or regenerate historical bytes as proof of identity.
Dirty worktree during an exact-head certification = STOP and classify the changed paths.
Network-dependent capability while offline = explicit unavailable/denied state, never silent success.
Partial install/migration failure = preserve logs and restore only from a verified backup or defined rollback path.
After a downstream failure, reuse already-passed upstream artifacts unless an input or falsifier changed.
