SUPPORTED SOURCE STARTUP
------------------------

  Double-click "Mucaro AI.app" in the checkout, or:
  ./"Mucaro AI.command"

Windows:
  Double-click "Mucaro AI.cmd"

Linux x86_64:
  ./"Mucaro AI.command"

GLOBAL OFFLINE MODE
-------------------
For an already prepared runtime:
  export MUCARO_AI_OFFLINE=1

Windows PowerShell:
  $env:MUCARO_AI_OFFLINE="1"

Expected behavior:
- local GUI/API loopback remains available;
- local source ingestion/retrieval/memory/planning/provenance/export remain local;
- explicitly configured loopback local-model service may remain available;
- remote model APIs, web fetch/session, web search, rendered public-web browsing,
  and governed tools requiring external networking fail closed with
  ERROR_OFFLINE_NETWORK_DISABLED.

MUCARO_AI_OFFLINE is an application capability boundary, not an OS firewall.

RUNTIME-INDEPENDENCE CONTRACT
-----------------------------
Human-readable:
  docs/RUNTIME_INDEPENDENCE.md

Machine-readable:
  _architecture/runtime_independence_v1.json

Certification rule:
Do not label a platform OFFLINE_INDEPENDENT until a complete prepared artifact
installs and first-launches on a clean controlled device with public networking
disabled, exercises every declared offline capability, persists local state,
shows no unexplained external connections, requires no mandatory host developer
tools, and has exact artifact hashes/manifests/receipts.

ARTIFACT / HASH VERIFICATION
----------------------------
macOS:
  shasum -a 256 <artifact>
Linux:
  sha256sum <artifact>
Windows PowerShell:
  Get-FileHash <artifact> -Algorithm SHA256

Compare the computed digest byte-for-byte with the release manifest/receipt.
A mismatch is a hard failure. Do not install, promote, or certify that artifact.

FAILURE HANDLING
----------------
- Preserve failing logs and exact commit/artifact SHA-256.
- Do not convert BLOCKED, OPEN, PROVISIONAL, or failed gates into PASS.
- Repair the narrow failing layer, then rerun affected and full regression gates.
- Remote/network failure under MUCARO_AI_OFFLINE=1 is expected only when the
  explicit offline-disabled status is returned; silent fallback is not PASS.
